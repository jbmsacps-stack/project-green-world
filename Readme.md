## 📌 About the Project

**Project Green World** is a free, non-commercial Global Warming awareness website created to help people understand the seriousness of climate change and environmental damage.

This project is not built for money, sponsorship, promotion, or personal financial gain.  
The creator receives **nothing in return** — no payment, no monetization, and no profit.

It is built purely from the intention to spread awareness, educate people, and encourage responsible thinking about the future of our planet.

The website will include information about:

- Causes of Global Warming
- Effects of Global Warming
- Practical Solutions
- Trusted support and donation links
- Awareness-focused educational content

---

## 🛠️ How This Project Was Built

Project Green World is being built as a **static multi-page website** using core front-end technologies.

The project uses:

- **HTML** for page structure
- **CSS** for layout, responsive design, styling, animations, and visual polish
- **JavaScript** for interactivity such as the language switcher, share button, and small UI effects

The website currently includes these pages:

- `index.html`
- `causes.html`
- `effects.html`
- `solutions.html`
- `donate.html`
- `disclaimer.html`

The site is designed to stay lightweight, readable, and simple to access without requiring login, backend, database, or monetized services.

---

## 🌐 English–Tamil Language Support

Project Green World includes an **English ↔ Tamil language switcher** built with JavaScript.

The language system uses custom HTML attributes such as:

```html
data-en="Causes of Global Warming"
data-ta="உலக வெப்பமயமாதலின் காரணங்கள்"
````

JavaScript reads these attributes and switches the visible text between English and Tamil.

This feature is included so climate awareness can be more accessible to Tamil-speaking users, while still keeping the website simple and static.

## ✨ Key Features

Project Green World currently includes several front-end features built manually using HTML, CSS, and JavaScript.

* 🌐 **English ↔ Tamil Language Switcher**
  Allows selected website text to switch between English and Tamil using JavaScript and `data-en` / `data-ta` attributes.

* 🔗 **Share Button**
  Uses browser sharing support where available, with a fallback method to copy the page link.

* 📱 **Responsive Design**
  The layout adjusts for desktop, tablet, and mobile screens using CSS media queries.

* 🧭 **Multi-Page Navigation**
  Includes separate pages for Home, Causes, Effects, Solutions, Donate, and Disclaimer.

* 🧱 **Semantic HTML Structure**
  Uses meaningful tags like `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.

* ♿ **Accessibility Basics**
  Includes keyboard focus styling, accessible navigation labels, and structured content sections.

* 🔎 **SEO-Friendly Foundation**
  Includes page titles, meta descriptions, and clean heading structure for better readability and search engine understanding.

* 🎨 **Nature-Themed UI**
  Uses a green visual direction, soft card styling, hover effects, and a clean awareness-focused layout.

* 🚫 **No Login / No Backend / No Monetization**
  The website is static, lightweight, free to access, and created only for awareness.
