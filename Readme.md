# Project Green World

Project Green World is a static multi-page awareness website focused on global warming, climate awareness, and environmental responsibility.

## Pages

- Home
- Causes
- Effects
- Solutions
- Donate
- Disclaimer

## Features

- Multi-page static website
- English ↔ Tamil language switcher
- Share button
- Donate page with trusted external links
- Responsive layout
- Accessible semantic HTML structure
- Lightweight CSS and JavaScript

## Tech Stack

- HTML
- CSS
- JavaScript

## Purpose

This project is created for educational and awareness purposes. It explains global warming in a simple and viewer-friendly way.

## Disclaimer

Project Green World does not collect donations directly. Donation links, if included, should always point to trusted external official sources.
