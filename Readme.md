## 🌍 About the Project

**Project Green World** is a static, multi-page awareness website dedicated to Global Warming, climate change, and environmental responsibility.

> This project is built with one purpose: **to spread awareness**. There is no payment, no monetization, and no profit involved — only a genuine effort to inform and educate.

The website covers:

- 🔥 **Causes** of Global Warming
- 🌊 **Effects** on the planet and humanity
- 💡 **Practical solutions** anyone can act on
- 🤝 **Trusted donation and support links**
- 📚 **Educational content** for all ages
- 🗣️ **English and Tamil** language support

### 🌐 English–Tamil Language Support

- JavaScript-powered English ↔ Tamil switcher
- Uses `data-en` and `data-ta` HTML attributes for translatable content
- Keeps the site fully static — no backend or database required
- Makes climate awareness accessible to Tamil-speaking communities

### 🖱️ User Interaction

- Native browser **Share** button with clipboard fallback
- Interactive button effects
- Hover effects on cards and navigation elements

### 📱 Responsive Design

- Optimized for **desktop, tablet, and mobile**
- Flexible card grid layouts
- Mobile-friendly navigation
- Overflow and spacing fixes for smaller screens

### ♿ Accessibility & SEO

- Semantic HTML5 structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- Meaningful `aria-label` attributes on buttons and navigation
- Clear heading hierarchy and keyboard focus styles
- Meta descriptions and SEO-friendly page titles
- Open Graph-ready page structure

## 🌐 Language Switcher

Tamil language support is built directly into the HTML using custom data attributes:

```html
<h3
  data-en="Causes of Global Warming"
  data-ta="உலக வெப்பமயமாதலின் காரணங்கள்">
  Causes of Global Warming
</h3>
```

JavaScript reads these attributes and updates all visible text when the user switches languages — no page reload, no backend, fully static.
