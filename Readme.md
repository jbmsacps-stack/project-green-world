## About

**Project Green World** is a static multi-page awareness website focused on Global Warming, climate change, environmental responsibility, and public education.

This project is not built for money, sponsorship, promotion, or personal financial gain. The creator receives **nothing in return** — no payment, no monetization, and no profit.

It is built purely from the intention to spread awareness, educate people, and encourage responsible thinking about the future of our planet.

> Project Green World is not a commercial platform.  
> It is a free awareness project created for education, understanding, and responsibility.

The website will include information about:

- Causes of Global Warming
- Effects of Global Warming
- Practical Solutions
- Trusted support and donation links
- Awareness-focused educational content
- English and Tamil support for better accessibility

## How This Project Was Built

Project Green World is being built as a **static multi-page website** using core front-end technologies.

The project uses:

| Area | Implementation |
|------|----------------|

## Language Switcher Logic

The English–Tamil switcher is built using custom attributes in HTML.

Example:

```html
<h3 
  data-en="Causes of Global Warming"
  data-ta="உலக வெப்பமயமாதலின் காரணங்கள்">
  Causes of Global Warming
</h3>
````

JavaScript reads these attributes and updates the visible text depending on the selected language.

This keeps the project static while still allowing multilingual support.
